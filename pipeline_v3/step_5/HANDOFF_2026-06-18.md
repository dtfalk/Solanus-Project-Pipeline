## Key realizations this session (the rethink)
1. **Within-page multi-document is already solved** in the gold labels (`doc_1/doc_2/…`).
   Verified against data. The ONLY open structural inference is **cross-page spans**.
2. **Text-first beats geometry-first** for spans. Evidence: Volume_1 has ~46% of pages
   "opener-less" (body, no greeting/origin/recipient) — geometry can't tell a continuation
   from a new opener-less document there. Text disambiguates. And text must be extracted
   anyway (RAG), so doing it first is reordering inevitable work to where it also solves
   the hardest inference.
3. **Casebooks (V3, V4) are different**: every page = one `doc_1` holding ~14 per-entry
   `src_content` boxes (V3 has a `struct_id`/page ledger id; V4 mostly none). The "what is
   a casebook document" call (per-page / per-person / per-notebook) is the biggest shape
   decision — defer it until we can READ a few casebook pages (text-first enables that).
   Casebooks have ~0% letter-style continuations.

## The agreed pipeline (amends STEP_5_PLAN §3–5)
1. **Mask** each page to its labeled polygons (IN PROGRESS — this run). White out
   everything unlabeled so full-page OCR is clean; doubles as a labeling-coverage audit.
2. **Dual text extraction** per page (David's design): a full-page pass over the masked
   page AND a per-polygon "zoom" pass. Store as a **sidecar keyed to polygon `id`** — gold
   geometry is NEVER mutated. Cross-check: per-polygon vs full-page disagreement = auto QA
   queue.
3. **Structure → per-document JSON**: group polygon-texts by `doc_k`, assemble cross-page
   spans (text-backed proposer + human confirm), emit per-document JSON with merged text +
   structured fields. Feeds RAG / NER / graph-RAG.

### One open decision (settle with a ~15–20 page calibration pass)
Per-polygon granularity: **(A)** blanket zoom on all ~22,100 polygons (max accuracy per
region, most cost, tiny crops can OCR worse on handwriting), vs **(B)** one structured
full-page call per page returning `{polygon_id: text}` (~1,400 calls, context-aided,
automatic alignment) + **targeted** zoom only where low-confidence/disagreement/high-stakes
(dates, names, ids). Leaning B+targeted; calibration decides. Corpus is mixed
handwritten/typed archival material → OCR quality is the real risk; measure before scaling.
